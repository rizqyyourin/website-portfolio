## Stack

- Nuxt 4
- Vue 3
- Tailwind CSS
- Three.js
- AOS (Animate On Scroll)
- Heroicons

## Development

```bash
pnpm install
pnpm run dev
```

App runs at `http://localhost:3000`.

## Build

```bash
pnpm run build
```

## Deployment

Deployed via GitHub Actions to a VPS behind PM2. See `scripts/deploy-vps.sh` for the production deploy flow.
